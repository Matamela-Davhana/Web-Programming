# Meetly - Smart Meeting Scheduler

Meetly is a simple web-based meeting scheduler that allows users to create meetings in their own time zone and generate sharable links. When someone opens the link, the meeting time is automatically adjusted to their local time zone.

---

## Features
- Create meetings with a **title** and **date/time**.
- Automatically detect the user’s **time zone**.
- Convert meeting times to **UTC** for universal sharing.
- Generate a **link** that encodes meeting details.
- When opened, the link displays the meeting in the visitor’s **local time zone**.
- Clean, modern UI with logo and branding support.
